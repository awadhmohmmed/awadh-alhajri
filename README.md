Training Program | البرنامج التدريبي

This project was developed as part of the Generative AI Solutions Development training program at SDAIA Academy, under the supervision of Latifah Abdulmohsen.

The project demonstrates the practical application of generative AI technologies, including:

* Large Language Models (LLMs).
* Prompt Engineering and structured RACE prompts.
* Reusable prompt templates.
* Responsible AI practices and safe handling of sensitive data.
* Document processing and information retrieval.
* Retrieval-Augmented Generation (RAG).
* Conversation memory and response evaluation.
